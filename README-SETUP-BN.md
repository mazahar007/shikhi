# শিখি (Shikhi) — E-Learning Platform MVP — সেটআপ গাইড

বাংলা ভাষায় প্র্যাকটিক্যাল স্কিল লার্নিং প্ল্যাটফর্ম। Next.js + Tailwind, Vercel ফ্রি হোস্টিং,
Supabase ফ্রি ডেটাবেস/অথ (v2 ধাপ), YouTube Unlisted ভিডিও।

> ⚠️ গুরুত্বপূর্ণ: এই ভার্সনটি **ডেমো মোডে** চলে — লগইন, এনরোল, অগ্রগতি, কুইজ ফলাফল
> ও অ্যাডমিন এডিট শুধু আপনার ব্রাউজারে (localStorage) সংরক্ষিত হয়, কোনো সার্ভারে যায় না।
> Supabase সংযুক্ত হলে আসল অ্যাকাউন্ট/ডেটাবেস চালু হবে — সেটি নিচের ধাপ ৩-এ আছে।

## ১. লোকালি চালানো

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে খুলুন: http://localhost:3000

বিল্ড যাচাই:

```bash
npx tsc --noEmit
npm run build
```

## ২. ফ্রিতে লাইভ করা (GitHub + Vercel)

1. GitHub-এ একটি নতুন রিপো তৈরি করুন (যেমন: `shikhi` বা `elearning-mvp`)।
2. এই প্রজেক্টের সব ফাইল (node_modules ও .next ছাড়া) রিপোতে আপলোড করুন।
3. Vercel ড্যাশবোর্ডে **Add New → Project → Import** করে রিপোটি সিলেক্ট করুন।
4. Framework: Next.js (অটো ধরা পড়বে), বাকি সেটিং ডিফল্ট রেখে **Deploy** করুন।
5. লাইভ URL হবে অনেকটা এরকম: `https://shikhi-....vercel.app`
6. পরে চাইলে নিজের ডোমেইন Vercel-এ যুক্ত করতে পারবেন।

এই ধাপে কোনো env var লাগবে না — ডেমো মোড এমনিতেই চলবে।

## ৩. Supabase সংযুক্ত করা (v2 — আসল ডেটাবেস/অথ)

1. https://supabase.com → নতুন প্রজেক্ট তৈরি করুন (Free plan)।
2. Supabase Dashboard → **SQL Editor → New query**-তে `supabase/schema.sql` ফাইলের
   পুরো কনটেন্ট পেস্ট করে **Run** করুন। এতে ৬টি টেবিল তৈরি হবে:
   users, courses, lessons, enrollments, quizzes, quiz_results (+ RLS পলিসি)।
3. Project Settings → API থেকে `Project URL` ও `anon public key` নিন।
4. Vercel-এ Project → Settings → Environment Variables-এ যুক্ত করুন:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. Redeploy করুন। এরপর `lib/`-কে Supabase-এর সাথে সংযুক্ত করার কোড (v2 কাজ)
   লাগবে — বর্তমান ডেমো কোড তখন Supabase দিয়ে প্রতিস্থাপন করা হবে।

**সতর্কতা:** Supabase Free plan ৭ দিন নিষ্ক্রিয় থাকলে pause হতে পারে — ড্যাশবোর্ড
থেকে ১ ক্লিকে resume করা যায়।

## ৪. অ্যাডমিন প্যানেল

- URL: `/admin`
- ডেমো পাসকোড: **1234**
- ট্যাব: **কোর্স** (add/edit/delete), **লেসন** (add/delete), **কুইজ** (add/delete)
- ডেমোতে এডিট শুধু আপনার ব্রাউজারে থাকবে; Supabase সংযুক্ত হলে সবার জন্য সংরক্ষিত হবে।

## ৫. YouTube Unlisted ভিডিও যুক্ত করা

1. YouTube Studio-তে ভিডিও আপলোড করে Visibility **Unlisted** করুন।
2. ভিডিওর আসল লিংক কপি করুন (যেমন: `https://www.youtube.com/watch?v=...`)।
3. `/admin` → লেসন ট্যাব → সংশ্লিষ্ট কোর্স বেছে নতুন লেসন যুক্ত করার সময়
   (বা সিড লেসন এডিট করে) URL-টি বসান।
4. লেসন পেজে ভিডিও স্বয়ংক্রিয়ভাবে এমবেড হবে।
5. **ভুয়া/আন্দাজে YouTube ID কখনো দেবেন না।** URL খালি থাকলে লেসন পেজে
   পরিষ্কার প্লেসহোল্ডার দেখাবে: “ভিডিও শিগগিরই যুক্ত হবে — Admin থেকে
   YouTube Unlisted লিংক যোগ করুন” — তবুও লেসন সম্পন্ন করা যাবে।
